# AtelierNeon Core Library for Go

This repository is implemented with [Go](https://go.dev/).

## How to Build

All build script is under script directory. You can run build script in project root for these platform:

- Run `.\script\build-windows.cmd` for Windows.
- Run `./script/build-linux.bash` for Linux.
- Run `./script/build-darwin.zsh` for macOS.

The build script will tell you what dependencies are missing when building. The known prerequisite is latest [Go SDK](https://go.dev/dl/).
